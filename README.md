# Site internet de suivi pour IFT3150

Ce site retrace les avancées faites dans le cadre du cours IFT3150 que j'ai (Alexis Lessnick) suivi à l'été 2026 à l'Université de Montréal. La structure du site était déjà fournie: Louis-Édouard Lafontant, du DIRO, a fourni un template pour le projet. Mon site est donc une branche du template de base, qu'il est facile de récupérer directement depuis le répertoire GitHub associé.
